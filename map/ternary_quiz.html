삼진법 퀴즈

규칙

이 퀴즈에서는 다음 규칙을 따르는 삼진법을 사용합니다:

  • a = 0
  • b = 1
  • c = 2

참고: 제시하신 예시 중 b+c=ca는 표준 삼진법(1+2=3_10 = 10_3 -> 'ba')과 다릅니다. 여기서는 표준 삼진법을 따르며, 따라서 b+c = ba로 간주합니다.

덧셈 예시

  • a + a = a (0 + 0 = 0)
  • a + b = b (0 + 1 = 1)
  • a + c = c (0 + 2 = 2)
  • b + b = c (1 + 1 = 2)
  • b + c = ba (1 + 2 = 3 → 103)
  • c + c = bb (2 + 2 = 4 → 113)
  • ba + b = bb (103 + 13 = 3 + 1 = 4 → 113)
  • ba + c = bc (103 + 23 = 3 + 2 = 5 → 123)
  • bc + b = ca (123 + 13 = 5 + 1 = 6 → 203)
  • bb + cc = bba (113 + 223 = 4 + 8 = 12 → 1103)
